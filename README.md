# Statistical Models
These are specific codes and data for the course of Statistical Models.

## Contents

The notebooks are numbered in the order of the course. A notebook that needs data lives in a folder of its own, next to its data.

| 06 | Mahalanobis distance |

| 08 | Linear regression |
| 09 | Maximizing gain (Bayesian) |
| 10 | Splines |
| 11 | Local polynomial regression |
| 12 | Robust regression |

## Requirements

Python 3.11 with `numpy`, `scipy`, `pandas`, `matplotlib`, `scikit-learn`, `statsmodels`, `ipywidgets`, `pygam`, `sympy`, `pymc` and `arviz`.
